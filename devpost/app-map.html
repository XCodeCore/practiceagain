How PracticeAgain works

Enter a basic algebra question. Check your working, read a short explanation if needed, then try a similar question yourself.

Follow one action: Check my step

You type a step→ app.mjs receives it→ attempts.mjs checks it→ app.mjs shows feedback
  1. public/src/app.mjs: find #step-form. This receives what you type when you press Check my step.
  2. public/src/attempts.mjs: find checkStep. It asks the maths checker whether your step keeps the correct answer. It records whether you needed help.
  3. public/src/app.mjs: find render. It puts the result on the screen.

This is a reference route through the actual source. It does not record completion of a hands-on code tour.

To change something, start here

  • Button names and instructions: public/src/app.mjs, render.
  • Short answer explanations: public/src/questions.mjs, lessonFor. displayAnswer chooses decimal or fraction display.
  • Maths rules: public/src/algebra.mjs, classify. Changes here need correctness checks.
  • Saved progress: public/src/storage.mjs, save and restore. It stays in the same browser and website.
  • Colours and spacing: public/styles.css.

A practice to reuse

Try a real example before adding more features. Feedback about entering a question versus entering a solving step led to separate labels and actions. The current journey is described in devpost/prd.md; mathematical and saved-progress checks live in tests/core.test.mjs.

On your next project, describe what a person should see, try it, then adjust the unclear part.

Open it again

From the project folder, run node server.mjs, then open PracticeAgain. Check the maths with node --test tests/*.test.mjs.
